# Dogwood_Splash-Testing

## Overview

Dogwood_Splash-Testing is a proof-of-concept splash page for the BC Government Wireless Guest Network.

This project was created to support the migration of Dogwood guest Wi-Fi internet access from the current Check Point UserCheck solution to Zscaler Internet Access (ZIA).

The application provides:

- BC Government branded splash page
- Acceptable Use Policy (AUP)
- Terms of Use acknowledgement
- User acceptance workflow
- Prototype user experience for testing within Zscaler

## Project Goal

The purpose of this project is to:

1. Validate that Zscaler can display a custom splash page.
2. Replicate the existing Dogwood guest Wi-Fi user experience.
3. Gather stakeholder feedback before production implementation.
4. Provide a foundation for future enhancements and automation.
